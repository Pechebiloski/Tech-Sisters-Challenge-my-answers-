# Desafio #01 — Número positivo, negativo ou nulo

**Dificuldade:** Iniciante · **Linguagem:** JavaScript

Recebe um número e informa se ele é **POSITIVO**, **NEGATIVO** ou **NULO**.

## Como rodar

```bash
node index.js
Casos de teste
Entrada	Saída
15	O número 15 é POSITIVO.
-8	O número -8 é NEGATIVO.
0	O número 0 é NULO.
Extras
Aceita vírgula como separador decimal (ex.: 2,5).

Digite sair para encerrar.

Valida entradas inválidas.
