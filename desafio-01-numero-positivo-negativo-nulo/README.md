# 💻 Tech Sisters | Desafio #01

## Número positivo, negativo ou nulo

> Desafio de lógica de programação proposto pela comunidade Tech Sisters.

### 📌 Sobre o desafio

Desenvolver um programa que receba um número informado pelo usuário e identifique se ele é positivo, negativo ou nulo (zero).

O programa também permite que o usuário realize várias classificações consecutivas, encerrando a execução ao digitar `sair`.

### 🛠️ Tecnologias utilizadas

- JavaScript
- Node.js
- Módulo `readline`

### ⚙️ Conceitos aplicados

- Entrada e saída de dados
- Funções
- Estruturas condicionais (`if`)
- Conversão e validação de valores numéricos
- Recursividade para repetição das entradas
- Tratamento de encerramento do programa

### 🧪 Casos de teste

| Entrada | Resultado esperado |
|---|---|
| `15` | O número 15 é POSITIVO. |
| `-8` | O número -8 é NEGATIVO. |
| `0` | O número 0 é NULO. |

### ▶️ Como executar

É necessário ter o Node.js instalado.

```bash
node index.js
```

O programa solicitará um número pelo terminal. Para encerrar, digite `sair`.
