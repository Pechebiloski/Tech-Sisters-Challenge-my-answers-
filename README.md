# 💗 Tech Sisters | Desafio do Código

Repositório dedicado às minhas soluções desenvolvidas durante o **Desafio do Código da comunidade Tech Sisters**.

Este espaço reúne desafios de lógica de programação realizados durante minha trajetória como estudante de Ciência da Computação, incluindo soluções enviadas dentro do prazo, correções de código e exercícios desenvolvidos posteriormente para aprofundar meus estudos.

♡ Mais do que cumprir desafios, este repositório documenta meu processo de aprendizagem e evolução na programação.

## ꒰ Desafios ꒱

| Desafio | Tema | Linguagem | Dificuldade | Status |
|:---:|---|:---:|:---:|---|
| [#01](./desafio-01/) | Número positivo, negativo ou nulo | JavaScript | Iniciante | Solução desenvolvida |
| [#03](./desafio-03/) | Meta de passos | JavaScript | Iniciante | Código corrigido • Não aprovado na submissão original |
| [#04](./desafio-04/) | Compra parcelada | JavaScript | Iniciante | Solução desenvolvida |

*Os desafios podem ser realizados fora do prazo oficial como parte dos meus estudos individuais.*
